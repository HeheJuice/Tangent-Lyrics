# Tangent Lyrics

[![GitHub 下載次數](https://img.shields.io/github/downloads/HeheJuice/Tangent-Lyrics/total?color=blue&label=GitHub%20%E4%B8%8B%E8%BC%89%E6%AC%A1%E6%95%B8&style=for-the-badge&logo=github&logoColor=white)](https://github.com/HeheJuice/Tangent-Lyrics/releases)
[![Android 版本需求](https://img.shields.io/badge/Android%20%E7%89%88%E6%9C%AC%E9%9C%80%E6%B1%82-%E2%89%A5%20SDK%2033-green?style=for-the-badge&logo=android)](https://developer.android.com/)

> 將你的本機音樂檔案變成可分享的歌詞卡片

</div>

## 功能特色

> **本機音樂解析** — 原生、零依賴，直接從音訊檔案擷取中繼資料、專輯封面與內嵌歌詞。

> **兩種卡片樣式** — 可產生標準專輯封面卡片，或歌詞卡片。

> **Monet 動態色彩** — 卡片會根據專輯封面動態調整背景漸層。

> **自適應版面配置** — 卡片寬高會智慧調整，完美符合你選擇的歌詞。
